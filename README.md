# archived_scripts

An archive of tool scripts I wrote before 2018. Some scripts depend on the software and environment I used at the time.

## ae2017

Adobe After Effects scripts and expressions.

| File | Purpose |
|---|---|
| `effect_catalog.jsx` | Lists the effects and categories available in the current After Effects installation. |
| `grid_layout.txt` | Arranges multiple layers in a fixed grid, with spacing controlled by sliders. |
| `optical_flare_panel.jsx` | Adds a small panel for quickly creating an optical flare layer from selected footage. |
| `optical_flare_setup.jsx` | An alternative optical flare setup script with additional handling for the new layer. |
| `rectangle_width_random.txt` | Randomly changes a rectangle's width within a limited range. |
| `strip_layout.txt` | Divides layers into even strips and calculates their size and position. |
| `width_variation.txt` | Another expression for randomly varying a rectangle's width. |

## manga-image-processing

Scripts for organizing and batch-processing manga images.

| File | Purpose |
|---|---|
| `combine_pages.py` | Builds a Nuke project that places images from the same group side by side. |
| `retouch.py` | A batch-processing tool for backing up, renaming, joining, converting, cropping, adjusting, and packaging manga images. |
| `retouch.bat` | Starts `retouch.py` from a Windows folder. |
| `resize_images.bat` | Batch-resizes PNG images in the current folder. |
| `convert_png.reg` | Adds a “Convert to PNG” command to the Windows image context menu. |
| `resize.reg` | Adds a context-menu command that resizes an image and outputs PNG. |
| `resize_jpeg.reg` | Adds a context-menu command that resizes an image and outputs JPEG. |
| `proxy.reg` | Adds a context-menu command for generating a small preview image. |
| `retouch.reg` | Adds a manga-retouching entry to the Windows folder context menu. |
| `smart_crop.reg` | Adds a smart-cropping entry to the Windows folder context menu. |
| `monochrome_retouch.reg` | Adds a monochrome-image processing entry to the Windows folder context menu. |
| `drawing.atn` | A collection of Photoshop drawing actions. |
| `handwriting.atn` | A collection of Photoshop handwriting-effect actions. |
| `lettering.atn` | A collection of Photoshop lettering actions. |
| `retouch.atn` | A collection of Photoshop retouching actions. |

# archived_scripts

Arkisto ennen vuotta 2018 kirjoittamistani työkaluskripteistä. Osa skripteistä riippuu tuolloin käyttämistäni ohjelmista ja ympäristöstä.

## ae2017

Adobe After Effects -skriptejä ja -lausekkeita.

| Tiedosto | Toiminto |
|---|---|
| `effect_catalog.jsx` | Luettelee nykyisessä After Effects -asennuksessa käytettävissä olevat tehosteet ja niiden luokat. |
| `grid_layout.txt` | Järjestää useita tasoja kiinteäksi ruudukoksi; välejä voi säätää liukusäätimillä. |
| `optical_flare_panel.jsx` | Lisää pienen paneelin, jolla valitusta materiaalista voi luoda nopeasti optical flare -tason. |
| `optical_flare_setup.jsx` | Vaihtoehtoinen optical flare -skripti, joka käsittelee uuden tason tilaa hieman laajemmin. |
| `rectangle_width_random.txt` | Muuttaa suorakulmion leveyttä satunnaisesti rajatulla vaihteluvälillä. |
| `strip_layout.txt` | Jakaa tasot tasalevyisiksi kaistoiksi ja laskee niiden koon ja sijainnin. |
| `width_variation.txt` | Toinen lauseke suorakulmion leveyden satunnaiseen vaihteluun. |

## manga-image-processing

Skriptejä mangakuvien järjestämiseen ja eräkäsittelyyn.

| Tiedosto | Toiminto |
|---|---|
| `combine_pages.py` | Rakentaa Nukessa saman ryhmän kuvista vierekkäin yhdistetyn projektin. |
| `retouch.py` | Mangakuvien eräkäsittelytyökalu varmuuskopiointiin, uudelleennimeämiseen, yhdistämiseen, muuntamiseen, rajaamiseen, säätämiseen ja pakkaamiseen. |
| `retouch.bat` | Käynnistää `retouch.py`-skriptin Windows-kansiosta. |
| `resize_images.bat` | Pienentää nykyisen kansion PNG-kuvat eräajona. |
| `convert_png.reg` | Lisää Windowsin kuvien pikavalikkoon “Muunna PNG-muotoon” -komennon. |
| `resize.reg` | Lisää pikavalikkoon komennon, joka pienentää kuvan ja tallentaa sen PNG-muodossa. |
| `resize_jpeg.reg` | Lisää pikavalikkoon komennon, joka pienentää kuvan ja tallentaa sen JPEG-muodossa. |
| `proxy.reg` | Lisää pikavalikkoon komennon pienen esikatselukuvan luomista varten. |
| `retouch.reg` | Lisää Windows-kansion pikavalikkoon mangakuvien retusointikomennon. |
| `smart_crop.reg` | Lisää Windows-kansion pikavalikkoon älykkään rajauksen komennon. |
| `monochrome_retouch.reg` | Lisää Windows-kansion pikavalikkoon mustavalkokuvien käsittelykomennon. |
| `drawing.atn` | Photoshop-toimintokokoelma piirtämiseen. |
| `handwriting.atn` | Photoshop-toimintokokoelma käsinkirjoitustehosteisiin. |
| `lettering.atn` | Photoshop-toimintokokoelma tekstityöhön. |
| `retouch.atn` | Photoshop-toimintokokoelma retusointiin. |
